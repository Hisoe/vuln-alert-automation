## 📖 Overview

Enterprise security teams are routinely overwhelmed by thousands of vulnerability alerts generated by traditional scanners. Relying solely on static CVSS severity scores leads to severe alert fatigue, as many "Critical" vulnerabilities are never actually exploited by threat actors in the wild.

This project implements a **Shift-Left Vulnerability Management** automation script written in Python. The script ingests a local asset inventory (CMDB/vulnerability scan report) and cross-references detected CVEs against live threat intelligence from the **CISA Known Exploited Vulnerabilities (KEV) Catalog**. If an active exploit vector is matched on an internal asset, the script engages an LLM (Google Gemini) to generate a non-technical, three-sentence business risk executive summary and routes an immediate high-priority alert payload via **Webhooks** to the Security Operations Center (SOC) chat infrastructure.

```text
[Local CSV Scan Report] 
       │
       ▼
[Python Automation Engine] ◄─── (Fetches Live CISA KEV JSON Threat Intel)
       │
       ├─► [No Active Exploit] ──► Log to console & suppress alert fatigue
       │
       └─► [CRITICAL MATCH]
                 │
                 ▼
       [Gemini LLM Engine] ──► Generates 3-Sentence Business Risk Summary
                 │
                 ▼
       [Discord/Slack Webhook] ──► Real-time Instant SOC Alert Issued
```

## ✨ Key Features

Threat-Intel-Driven Prioritization: Bypasses arbitrary CVSS thresholds by identifying vulnerabilities actively being weaponized in the wild.

Automated Data Ingestion: Connects dynamically to the live CISA KEV JSON database feed.

Context-Aware AI Summarization: Employs LLM integration to automatically translate highly technical CVE data into actionable, jargon-free business risks for executive stakeholders.

Real-Time SOC Communication Channel: Eliminates email delays by using secure webhook integrations to instantly ping operation spaces (Discord/Slack).

## 🚀 Prerequisites & Installation

1. Clone the Repository
```text 
Bash
git clone https://github.com/Hisoe/vuln-alert-automation.git
cd vuln-alert-automation
```

2. Set Up a Virtual Environment

Isolate project dependencies by building a local virtual environment:
```text
Bash
# Create the environment
python -m venv venv

# Activate the environment
# On Windows (Command Prompt):
venv\Scripts\activate
# On Windows (PowerShell):
.\venv\Scripts\Activate.ps1
# On Mac/Linux:
source venv/bin/activate
```

3. Install Dependencies

Install the required verified packages inside the virtual environment:
```text
Bash
pip install requests google-generativeai
```

## ⚙️ Configuration & Usage

1. Setup Environment Secrets
Open vuln_alert.py and configure your API tokens and alert routing endpoints:
 * GEMINI_API_KEY: Obtain a free API key via Google AI Studio.
 * DISCORD_WEBHOOK_URL: Generate an Incoming Webhook URL within your target Discord/Slack channel integrations panel.

```text
Python
# --- Configuration Hooks ---
GEMINI_API_KEY = "YOUR_API_KEY_HERE"
DISCORD_WEBHOOK_URL = "[https://discord.com/api/webhooks/](https://discord.com/api/webhooks/)..."
⚠️ Security Warning: Never commit your live API keys or Webhook URLs to a public GitHub repository. Ensure placeholders are substituted before running a code push.
```

2. Execute the Script
Run the automated pipeline from your activated terminal:
```text
Bash
python vuln_alert.py
```

Target Host: WEB-FRONTEND-02  
Vulnerability: CVE-2021-44228 (Actively Exploited!)  
Affected Software: Apache Log4j 2.14.0
